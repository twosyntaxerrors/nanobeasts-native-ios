# Batch 6 Prompt Set

All concepts use the approved 10K Steps, 5 Day Streak, and First Hatch badges
as finish/quality references. Shared direction: dimensional hard-enamel
Nanobeasts field-research artifacts, large readable symbols, colorful jewel
enamel, polished dark metal, white review background, and no generic esports
crest treatment.

1. **Hatchery Master / 25 hatches**  
   A circular incubation command station with a luminous central egg and five
   colorful opening incubation pods.

2. **Starter Set / 3 species**  
   Three interlocking specimen lenses containing clearly different biological
   textures: blue scales, green leaf veins, and magenta crystal feathers.

3. **Avid Collector / 15 species**  
   A hexagonal specimen vault with six distinct biological signatures feeding
   into a faceted archive crystal.

4. **30 Day Streak**  
   The exact numeral `30` physically sculpted from a molten flame ribbon and an
   unbroken golden fire orbit with a cyan continuity spark—never ordinary type.

5. **Goal Veteran / 50 goal days**  
   The exact numeral `50` constructed from a mint checkpoint route and a cyan
   target portal with a checkmark—not printed or varsity lettering.

6. **Hiker / distance tier 15**  
   A unit-neutral bootprint climbing a faceted mountain, with a glowing
   switchback route embedded in the tread and a summit beacon.
