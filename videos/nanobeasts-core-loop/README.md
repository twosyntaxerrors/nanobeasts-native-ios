# Nanobeasts Core Loop Demo

A 15.8-second silent portrait demo for the onboarding “Here’s how it works” page.

The sequence explains the product in the order users experience it:

1. Real steps fill an egg’s hatch energy.
2. The egg hatches into Tutoria, a living walking companion.
3. The new creature unlocks a Field Dex entry.
4. Consistent walking earns an achievement badge.

The visual thesis is simple: Nanobeasts is a living Pokédex unlocked by real movement. Walk. Discover. Repeat.

The app uses the rendered MP4 as a local bundled onboarding resource so the demo is available without a second hosted-media request. The source composition is `index.html`; the real Tutoria egg, creature, and badge assets are in `assets/`.
